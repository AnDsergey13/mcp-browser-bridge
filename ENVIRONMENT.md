## Чеклист для проверки на хосте (выполняет пользователь)

1. **Доступ к порту.** Rootless podman (ExitBox): хост НЕ маршрутизирует до
   сети контейнера (curl на IP контейнера виснет), publish-флага у exitbox нет.
   Решение: unix-сокет `.bridge/bridge.sock` в корне репозитория (общая
   bind-mount папка) + socat-релей на хосте (`start-relay.sh`, SETUP.md §1).
   Проверка: `curl 127.0.0.1:18777` → `426 Upgrade Required`.
2. **User-Agent LibreWolf** (спуфится!): в консоли браузера
   `navigator.userAgent` → записать сюда:
   - UA: `…заполнить…` (понадобится в фазе 5 для даунлоадера)
3. **Политика cookies LibreWolf** (удаление при выходе?):
   - `…заполнить…` (влияет на живучесть сессий между перезапусками браузера)
4. **Установка расширения (разработка):** `about:debugging#/runtime/this-firefox`
   → Load Temporary Add-on → `extension/manifest.json`. Слетает при
   перезапуске браузера — на период разработки принимаем; постоянная
   установка позже через `web-ext sign --channel unlisted` (нужен аккаунт AMO).
5. **Секрет моста:** при первом старте сервера печатается в лог и лежит в
   `.bridge/secret` в корне репо (0600, переживает пересоздание контейнера).
   Ввести один раз в настройках popup расширения.
6. **Хост-права:** при первом подключении popup предложит выдать
   `<all_urls>` (кнопка, один раз; дальше доступ режется policy.yaml).
