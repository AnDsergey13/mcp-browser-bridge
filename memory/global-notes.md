# Глобальные заметки и рекомендации (не безопасность — она в policy.yaml)

Сюда — общие пожелания к работе агента с сайтами. Специфичное для сайта —
в `memory/domains/<domain>.md`.

Примеры того, что имеет смысл писать:
- «Скачанные материалы курса складывать в downloads/cps3/»
- «Если товара нет — предложить аналог и остановиться до ответа»

## UX-долг: кнопка «Выдать доступ к сайтам» (2026-09-19, пользователь)

После перезагрузки/переустановки временного дополнения host-разрешение
`<all_urls>` слетает → инжектор «НЕ зарегистрирован», все инструменты дают
CONTENT_SCRIPT_ABSENT, а пользователь не понимает почему. Нужно сделать
заметнее: бейдж/баннер в popup (красный статус вместо строки мелким текстом),
в SETUP.md «Быстрый рестарт» — шаг проверки статуса инжектора. Не забыть при
коммите следующей порции.

## Правила работы с вкладками (от пользователя, 2026-08-13)
- Линейная навигация — в ТЕКУЩЕЙ вкладке (act.click или tab.open с tabId).
  Новую вкладку открывать только осознанно: сохранить страницу для сравнения
  или «досмотреть позже», пока основная вкладка идёт дальше.
- Не закрывать и не переиспользовать вкладки, которые открыл не ты.
- tabId — стабильные ID (не позиция): пользователь может перетасовывать
  вкладки, это безопасно; но после перезапуска браузера ID новые —
  начинать с tab.list.

## Универсальные грабли моста (2026-10-10, приёмка Ж.1–3)
- **После перезагрузки расширения** (⟳ на chrome://extensions / временное
  дополнение в FF) content script во вкладках — «сирота» старой сборки.
  С 2026-10-11 это закрыто: reinjectOpenTabs переинжектирует вкладки сам
  (84359d2 + compat-фикс 2482b23) — F5 нужен только если домен получил
  session-грант через баннер (он не порождает policy.update, бэклог).
- **eval-runner НЕ поддерживает top-level await и `return`**: выражение
  исполняется через eval(). Асинхронку — цепочкой `.then(...)` или async-IIFE
  последним выражением (awaitPromise:true дождётся Promise).
- **Длинный page.eval**: потолок `timeout_ms` = `eval_timeout_ms` домена в
  policy.yaml (дефолт 30 с, максимум 300 с). Таймаут-цепочка: контент →
  background +10 с → транспорт сервера +15 с — безликий TIMEOUT вместо
  EVAL_TIMEOUT означает, что сработал сторож background/транспорта.
- **blob:/data: в file.download (Ж.1)**: policy по домену ВКЛАДКИ; blob чужого
  origin → VALIDATION_ERROR. blob читается срезами через scripting world:MAIN —
  от CSP страницы не зависит.

## Уроки баннер-комплекта и живой приёмки (2026-10-11/12)

Дорогие ошибки — не повторять:
- **«browser существует ⇒ Firefox»**: ранний выход шима по наличию
  `globalThis.browser` сломался на Chromium ≥128, где `browser` — нативный
  алиас `chrome.*` с MV3-API только. Правильно: Firefox определять по
  `getBrowserInfo`, пробелы алиаса дочинять точечно (compat-browser.js).
- **`browser === chrome` — один объект**: присвоение `browser.tabs.x = fn`
  мутирует и `chrome.tabs.x`; адаптер executeScript вызвал сам себя до
  RangeError. Правило: перед делегированием в «легаси»-API проверять, что это
  не ты сам (`legacy !== myFn`).
- **Липкий lastError без авто-сброса**: ошибка executeScript сутки выглядела
  актуальной в popup. Правило: кто пишет ошибку, тот и стирает её при первом
  успехе того же пути (tryInjectContentScripts так и делает).
- **beep v1**: без `resume()` suspended AudioContext играл молча; одиночный
  короткий сигнал легко пропустить → тройной «пи-пи-пи».
- **Визуальная приёмка перевеса баннера бесполезна**: MutationObserver
  перевешивает микрозадачей, раньше кадра — «не мигнул» ≠ «не перевесился».
  Приёмка только инструментальная: before/after-замер из консоли страницы.

Нейтральные находки (не баги, не чинить):
- **`tab.active` — per-window**: вкладка в отдельном окне остаётся «активной»
  при свёрнутом браузере; для уведомления проверять и `window.focused`.
- **Щелчок на старте тона в LibreWolf**: воспроизводится и на стороннем
  tone-generator (onlinemictest), не зависит от громкости и формы волны,
  сглаживание атаки (20 мс рампа) НЕ помогло — артефакт аудиостека
  Firefox/железа. В Chromium чисто. Кодовым сглаживанием не возвращаться.
- **Много похожих localhost-вкладок** → консоль DevTools легко открыть не на
  той; вкладку с живым баннером искать по маркеру `[Мост]` в заголовке.

Хорошие решения — повторять:
- Сигнатурный retryable-паттерн вместо one-shot флага (reinjectOpenTabs:
  сигнатуру помечать только ПОСЛЕ успеха — сбой остаётся retryable).
- reason-поле в consent («click»/«timeout»/«replaced») — deny-кэш только по
  явному клику, таймаут и замещение его не отравляют.
- Мелкие коммиты по одному логическому изменению + прогон обоих наборов
  тестов до коммита.
