# Глобальные заметки и рекомендации (не безопасность — она в policy.yaml)

Сюда — общие пожелания к работе агента с сайтами. Специфичное для сайта —
в `memory/domains/<domain>.md`.

Примеры того, что имеет смысл писать:
- «Скачанные материалы курса складывать в downloads/cps3/»
- «Если товара нет — предложить аналог и остановиться до ответа»

## Правила работы с вкладками (от пользователя, 2026-08-13)
- Линейная навигация — в ТЕКУЩЕЙ вкладке (act.click или tab.open с tabId).
  Новую вкладку открывать только осознанно: сохранить страницу для сравнения
  или «досмотреть позже», пока основная вкладка идёт дальше.
- Не закрывать и не переиспользовать вкладки, которые открыл не ты.
- tabId — стабильные ID (не позиция): пользователь может перетасовывать
  вкладки, это безопасно; но после перезапуска браузера ID новые —
  начинать с tab.list.
