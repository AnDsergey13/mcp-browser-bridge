## Шаг 1 — Оси (морфологический анализ)
Разбей решение на 3-6 независимых осей. Оси — это вопросы: «за счёт чего?»
(источник энергии/эффекта), «где?», «когда?», «кто/что выполняет?»,
«какой носитель/среда?», «постоянно или по событию?».
Пример (доставка горячего): источник тепла | удержание тепла |
момент нагрева | форма тары.

## Шаг 2 — Значения осей, включая крайние
Для каждой оси 3-5 значений. Обязательно добавь крайние: «ноль»
(этого элемента вообще нет), «максимум», «наоборот».
Крайние значения — не мусор, а выход из привычного класса решений.

## Шаг 3 — Сборка 5-7 непохожих комбинаций
Не перебирай всё. Собери 5-7 комбинаций, максимально далёких друг от
друга (разные значения по большинству осей).
Одна комбинация = одна концепция, механизм в одну фразу.

## Шаг 4 — Инвентивные операторы (SIT) на две лучшие концепции
- Вычитание: убери самый «главный» компонент. Как функция выполнится без него?
- Объединение задач: существующий компонент берёт на себя вторую функцию.
- Разделение: разнеси конфликтующие требования во времени, в пространстве
  или по условию.
- Умножение: добавь копию компонента с одним изменённым свойством.
- Зависимость атрибутов: пусть параметр X сам меняется в зависимости от Y,
  без управления извне.

## Шаг 5 — Биомимикрия (один вопрос)
Как эту функцию решают живые системы (удержание тепла, транспорт,
сцепление, фильтрация, сигнализация, самовосстановление)?
Есть внятный аналог — добавь концепцию на его основе.

## Шаг 6 — Фильтр и выдача
Оцени концепции по трём метрикам: эффект / затраты / сложность.
Доминируемые (хуже другой по всем трём) — выброси. Противоречивые
(«дёшево, но хрупко») — не выбрасывай, пометь и попробуй разрешить
оператором разделения из шага 4.
Выдай 3 лучшие: механизм / почему лучше остальных / главный риск /
самая быстрая проверка. Перед выдачей сверь с числами и запретами условия.
