Lab-полигон

Тестовые страницы для живой проверки инструментов моста. Запуск: python3 -m http.server 18547 из каталога lab/.

Без параметра ?seed=N все страницы чистые — инъекций нет.

  • form.html — форма (text/password/select/checkbox/submit), кнопки «Оплатить заказ» и «Удалить аккаунт» (gated-классификатор: pay/submit/delete)
  • shadow.html — open shadow root с интерактивными элементами
  • frames.html — same-origin iframe
  • hidden.html — скрытый текст (display:none, спойлеры) и скрытые embed (page.extract: Д1+Д3)
  • spa.html — DOM-мутации с задержкой + бесконечная лента (page.wait_for, STALE_REF, page.scan)
  • api.html — fetch/XHR к data.json (net.list)
  • media.html — видео/HLS-заглушка и картинки
  • ws.html — WebSocket к локальному echo (деградация без спама)

Канареечные endpoint'ы red-team режима: canary/<id>/, files/secret-<id>.txt. См. README.md.
