# SETUP.md — установка и запуск моста (хост + контейнер)

## Одноразовая настройка

### 1. Контейнер (ExitBox): подключение хоста к серверу

Rootless podman в ExitBox: сеть контейнера internal-only, хост до IP контейнера
НЕ достучится (проверено), флага publish портов у `exitbox run` нет. Поэтому
мост ходит через **unix-сокет в общей папке** (тот же приём, что docker.sock):
сервер слушает `/workspace/.bridge/bridge.sock`, а это тот же файл, что
`.bridge/bridge.sock` в папке проекта на хосте.

На хосте, в папке проекта, запусти релей (одна команда, оставить работать):

```fish
socat TCP-LISTEN:18777,bind=127.0.0.1,fork,reuseaddr UNIX-CONNECT:$PWD/.bridge/bridge.sock
```

Проверка: `curl 127.0.0.1:18777` → ответ `426 Upgrade Required`. URL для
расширения: `ws://127.0.0.1:18777`. После пересоздания контейнера просто
перезапусти этот socat — путь не меняется.

Сервер продолжает слушать и TCP `0.0.0.0:18777` — если когда-нибудь появится
проброс портов, расширение можно переключить на `ws://<IP>:18777` напрямую.

Общая папка (эта, `/workspace`) монтируется — в ней живут `policy.yaml`,
`memory/`, `downloads/`, `.bridge/secret`, и всё это переживает пересоздание
контейнера.

Первый старт сервера:

```bash
cd /workspace/bridge-server
npm install   # один раз
npm start     # или его запустит Kimi Code CLI как MCP-сервер
```

При первом запуске в логе печатается **секрет** (лежит в
`/workspace/.bridge/secret`, права 0600). Он постоянный между контейнерами.

MCP уже настроен в `.kimi-code/mcp.json` — новые сессии Kimi Code CLI
подключают сервер автоматически (`/mcp` — статус).

### 2. Браузер (Firefox / LibreWolf)

1. `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** →
   выбрать `extension/manifest.json` из этой папки.
   (Временное расширение слетает при перезапуске браузера — загружай заново.
   Постоянная установка позже: `web-ext sign --channel unlisted`.)
2. Открыть popup расширения → **Настройки**: URL `ws://127.0.0.1:18777`,
   секрет из шага 1 → Сохранить.
3. Там же кнопка **«Выдать доступ к сайтам»** (`<all_urls>`, один раз;
   реальный доступ режется policy.yaml — default-deny).

> **Разработка: Reload расширения ≠ обновление контент-скриптов.**
> После «Reload» в `about:debugging` уже открытые вкладки продолжают
> выполнять СТАРЫЙ код content scripts (фолбэк-инжекция срабатывает,
> только если приёмник совсем мёртв). Чтобы вкладка подхватила новый
> код — перезагрузи саму вкладку (F5) или навигируй её заново.

## Каждая новая сессия (новый контейнер)

1. Запусти контейнер из папки проекта на хосте:
   `exitbox run kimi --no-resume -- --yolo`
   (папка проекта монтируется как `/workspace`).
2. Загрузи расширение, если браузер перезапускался.
3. Расширение подключится и покажет запрос **«Новая сессия агента —
   разрешить?»** (уведомление + кнопка в popup). Подтверждается **один раз
   на контейнер** — дальше все правила из `policy.yaml` действуют
   автоматически.
4. Всё. Говори агенту задачу («по пресету course выгрузи урок N…»).

Свёрнутый браузер — не помеха: соединение живёт, пока браузер запущен.
Закрытый браузер = `BROWSER_OFFLINE`.

## Управление на ходу (popup)

- **Пресет** — селектор; переключение мгновенное.
- **Грант текущему домену** — чекбоксы capabilities (`read` / `interact` /
  `download`, по умолчанию read+interact) + кнопка «Выдать / обновить грант».
  Для уже выданного домена чекбоксы предзаполнены текущими значениями —
  доступ можно поправить в любой момент. Все галочки сняты = отзыв гранта.
  Действует на сессию (живёт в памяти сервера).
- **Гранты сессии** — список выданных разовых грантов с кнопкой «Отозвать»
  у каждого: доступ закрывается мгновенно (сервер шлёт свежий policy.update,
  домен выпадает из match_patterns). Пресетные домены — правкой `policy.yaml`.
- **ПАУЗА** — красная кнопка, мгновенно останавливает агента.
- **Авто-пауза** — вкладки, остановленные из-за капчи/челленджа/2FA, с
  кнопкой «Возобновить».
- **Журнал** — 20 последних действий агента.

Gated-действия (оплата, логин, submit, удаление) показывают баннер поверх
страницы: Разрешить / Запретить / Разрешить подобные 10 мин. Таймаут
120 с = запрет.

## Правила

- Безопасность — только в `policy.yaml` (домены, capabilities, gated,
  hard_floor). Hot-reload: сохранил файл — расширение и агент получили
  обновление.
- Рекомендации по сайтам — `memory/domains/<domain>.md`, общие —
  `memory/global-notes.md`.
- Аудит всех решений — `memory/policy-audit.jsonl`; журнал шагов —
  `memory/journal.jsonl`; скачанное — `downloads/` + `downloads/manifest.jsonl`.
