# userscripts/

Сюда подключаются юзерскрипты. Конвенция: **каждый юзерскрипт — отдельный
репозиторий**, в этот проект он подключается **git-сабмодулем** (без копий;
обновления видны через `git submodule status`).

Все команды — из корня этого репо, на хосте. `<путь>` = `userscripts/<имя>`;
команды без `<пути>` (`status`, `foreach`, `update --remote`) работают сразу
по ВСЕМ сабмодулям — неважно, сколько их и как называются.

## Шпаргалка по сабмодулям (универсальная)

**Подключить новый скрипт:**

```bash
git submodule add <URL-репо-скрипта> <путь>
git commit -m "chore(userscripts): add <имя> submodule"
```

Локальный путь как URL работает, но ломается на другой машине; для
переносимого репо — URL форжа (codeberg/github/…). Смена URL задним числом:

```bash
git submodule set-url <путь> <новый-URL>
git submodule sync
git add .gitmodules && git commit -m "chore(userscripts): repoint <имя>"
```

**Проверить состояние (самая частая команда):**

```bash
git submodule status
# начало строки:  « » = ок;  «+» = внутри сабмодуля выбран другой коммит
# (новые правки или недокачанный bump);  «-» = не инициализирован
```

Есть ли свежие коммиты наверху, ничего не меняя локально:

```bash
git submodule foreach 'git fetch origin && git log --oneline HEAD..origin/main'
# пусто = обновлений нет
```

**Подтянуть свежее во все сабмодули и зафиксировать указатели:**

```bash
git submodule update --remote
git add userscripts/ && git commit -m "chore(userscripts): bump submodules"
```

**Работа над скриптом:** идёшь в `<путь>` — это обычный репо: правишь,
коммитишь, пушишь ТАМ. Потом в этом репо фиксируешь новый указатель:

```bash
git add <путь> && git commit -m "chore(userscripts): bump <имя>"
```

Порядок важен: сначала push ВНУТРИ сабмодуля, потом bump снаружи — иначе
указатель будет ссылаться на коммит, которого нет на форже, и чужой клон
сломается.

**Отключить/удалить сабмодуль:**

```bash
git submodule deinit -f <путь>     # отключить (пустая папка, запись осталась)
git rm <путь>                      # удалить совсем (коммитит сам)
rm -rf .git/modules/<путь>         # зачистка хвоста после git rm
```

**После свежего клона этого репо** (папки сабмодулей пустые):

```bash
git submodule update --init
```
